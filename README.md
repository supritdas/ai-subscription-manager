# AI Subscription Manager

AI Subscription Manager is an agentic AI application built with Python, Groq, the OpenAI Agents SDK, and SQLite. It tracks monthly subscriptions, calculates spending, manages a monthly budget, checks renewal dates, and provides cost-saving recommendations. The two main tools demonstrated in the project are `add_subscription(name, cost, renewal_date)` and `get_monthly_total(request)`. The agent also uses tools for retrieving subscriptions, managing the budget, calculating yearly cost, and checking upcoming renewals. SQLite stores subscription and budget information so data from earlier interactions can be retrieved and used later.

The agent demonstrates the three required agentic behaviors: it calls tools instead of only generating text, it performs multi-step work by retrieving the budget, monthly total, and subscriptions before deciding what cancellation to recommend, and it remembers earlier information through persistent SQLite memory. For example, after the user sets a ₹2000 budget and adds subscriptions, a later request such as “What should I cancel to get back under budget?” does not require the user to repeat those details; the agent retrieves the stored state and reasons over it. The notebook demo shows the tool calls, tool results, and final responses for multiple goals.

One honest failure occurred during development when Groq rejected one of the generated tool schemas with a `400 invalid_request_error` because the schema contained a `required` field without the corresponding `properties` definition. A later tool-call attempt also failed because the model generated invalid JSON arguments. I handled this by making the tool arguments explicit and required, ensuring every required argument had a matching schema property, and updating the agent instructions to provide valid JSON arguments. After the fix, the tool calls and complete multi-step tests worked successfully.
